### Fixed
- **📺 Full-screen video on another monitor.** The taskbar widget no longer shows over a full-screen video on a second or third monitor after you click back on your main screen. It now stays hidden as long as a full-screen window covers that monitor's taskbar.
- **📦 Package-manager installs.** A silent install (winget, scripts) no longer starts the app by itself. Updates from inside the app still restart it as before.

### New
- **🌐 Website:** [valuex-creative.github.io/Windows-AI-Quota-Bar](https://valuex-creative.github.io/Windows-AI-Quota-Bar/).
- **🔏 Build provenance.** This release is built by GitHub Actions from the tagged source, and both downloads carry a signed GitHub attestation. Check it with:
  ```
  gh attestation verify WindowsAIQuotaBar-Setup-0.5.0.exe -R valuex-creative/Windows-AI-Quota-Bar
  ```

### Install
Download **`WindowsAIQuotaBar-Setup-0.5.0.exe`** and double-click it. It installs for your user only and needs no admin rights or .NET. Earlier versions update themselves.

The in-app updater checks each installer's signature. Update-signing key fingerprint: `7d8b52a2253d4bbb99f303a4c94dc94f5e806827072e01ff5cd3a172edbaee13`.

The installer is not Authenticode-signed yet. If SmartScreen warns you, choose **More info → Run anyway**.
